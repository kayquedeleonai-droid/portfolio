# Portfólio — Kayque Deleon

Site estático publicado em **portfolio.kayquedeleon.app** (Cloudflare Workers, static assets).

- `public/index.html` — página única; a lista de marcas e peças fica no array `BRANDS` no fim do arquivo.
- `public/media/` — vídeos (`nome.mp4`), capas (`nome.jpg`) e previews do hover (`nome-preview.mp4`).
- `public/logos/` — logos das marcas. Para trocar um logo em texto, coloque o arquivo aqui e preencha `logo:` na marca.

Limite do Cloudflare: 25 MiB por arquivo.
